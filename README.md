# TheGandalf Guide

Инструкции для клиентов FunPay: вход в PlayStation, вход на почту и решение проблем.
Статический сайт (HTML + CSS + JS), языки RU / UA / EN, светлая и тёмная тема. Работает на GitHub Pages без настроек.

## Публикация на GitHub Pages
1. Создайте **публичный** репозиторий на GitHub (например, `funpay-guide`).
2. Загрузите в него **содержимое** этой папки (не саму папку): `index.html` должен лежать в корне репозитория. Файл `.nojekyll` тоже нужен.
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Обновление: загрузите изменённые файлы поверх старых и сделайте commit. Ссылки на CSS/JS содержат версию (`?v=…`), поэтому клиенты сразу получат новую версию без очистки кэша.

## Структура
| Файл / папка | Что это |
|---|---|
| `index.html` | главная, выбор инструкции |
| `playstation.html` | вход в PlayStation (2 вводных шага + 15 шагов в 3 этапа) |
| `email.html` | вход на почту Outlook + запасная почта |
| `troubleshooting.html` | решение проблем: вопросы с поиском |
| `thanks.html` | «Спасибо за покупку»: открывается после кнопки «Завершить», напоминает подтвердить заказ |
| `404.html` | страница «не найдено» (GitHub Pages показывает её сам) |
| `assets/css/*.css` | оформление: у каждой страницы свой файл, только нужные ей стили |
| `assets/app.js` | поведение сайта (сжатый) |
| `assets/lang/<страница>.<язык>.js` | тексты: для каждой страницы и каждого языка отдельно (русский грузится всегда, другой язык — только если выбран) |
| `assets/fonts/` | шрифты Inter и Unbounded (свои, без Google Fonts) |
| `assets/img/` | скриншоты (WebP) и QR-коды PlayStation App |

Файлы в `assets/css`, `assets/lang` и `assets/app.js` собраны и сжаты автоматически, править их вручную неудобно — лучше просить правки через генератор.
При обновлении загружайте папку `assets` целиком: старые `assets/style.css` и `assets/lang/<страница>.js` больше не нужны, их можно удалить.

## Скорость
- Всё, что движется постоянно, анимируется только через `transform` и `opacity` — эту работу делает видеокарта, страница не перерисовывается.
- **Лёгкий режим** для слабых устройств (класс `lite` у `<html>`): включается сам, если у устройства мало памяти или ядер, включена экономия трафика, или по замеру при первом открытии сайт показывает меньше ~35 кадров в секунду. Дизайн тот же, но без постоянных декоративных эффектов и тяжёлых теней. Решение запоминается (`gg:lite`); чтобы сбросить — удалить этот ключ в `localStorage`.
- Страницы сайта подгружаются заранее, когда на ссылку навели курсор или начали нажимать (Speculation Rules) — переход почти мгновенный.
- Далёкие разделы и длинные списки не рисуются, пока до них не дошли (`content-visibility`).

## Что хранится у клиента
Прогресс по шагам, статус чтения (какие страницы были открыты хотя бы 10 секунд), выбранный язык, тема и чек-лист после покупки хранятся только в браузере клиента (`localStorage`, ключи `gg:*`). На сервер ничего не отправляется, сторонних скриптов и счётчиков нет.

## Защита текста
Запрещены выделение и копирование текста, правый клик, перетаскивание картинок, печать и горячие клавиши инструментов разработчика (F12, Ctrl+Shift+I/J/C, Ctrl+U/S/P). В полях ввода (поиск) всё работает как обычно.
Выключить защиту на странице: `<html lang="ru" data-protect="off" …>`.
Полностью скрыть код страницы в браузере невозможно — защита отсекает обычных посетителей и простое копирование.
